# 画面・UI 仕様

画面は 1 枚だけで、上から次の順に並べます。

```
┌───────────────────────────────────────┐
│ 第1章 消えた夜警  通常解決 未達成  真解決 未達成  手がかり 0/3   v0.1.0 │ ← ステータス
├───────────────────────────────────────┤
│ ┌───────────────────────────────────┐ │
│ │ CAM-03 3F 東側廊下          ● REC │ │
│ │ LIVE 02:47:12                     │ │ ← 監視モニター
│ │          （監視映像）              │ │
│ └───────────────────────────────────┘ │
├───────────────────────────────────────┤
│ [CAM-01][CAM-02][CAM-03] [現在の映像][過去の映像]  [状態を保存する][最初から] │ ← 操作ボタン
├───────────────────────────────────────┤
│ 【私】                                 │
│ 三上さん、応答してください。          ▼ │ ← テキストウィンドウ
├───────────────────────────────────────┤
│ ▶ 3F のカメラ（CAM-03）を確認する      │ ← 選択肢
└───────────────────────────────────────┘
```

## 雰囲気

- 深夜の薄暗い監視室。黒・ダークグレーを基調にする。
- 映像の色: 現在の映像は緑、過去の映像はアンバー。テキストウィンドウの左の線や、選ばれているボタンの色もこれに合わせる。

## 監視モニター

- 16:9。320x180 の粗い映像を拡大して表示する。
- 演出: ざらついたノイズ、走査線、上から下へ流れる明るい帯、画面の端の暗さ、ときどき起きる横方向のずれ、ちらつき。
- カメラや映像モードを切り替えた瞬間は、映像を大きく乱す。
- 左上にカメラ名・場所・モード・時刻、右上に「● REC」（過去の映像では「◀◀ PLAYBACK」）を表示する。

## テキストウィンドウ

- 話している人の名前を【 】で表示する（地の文は名前なし）。
- 1 文字ずつ表示する。表示中にクリックすると全文を出し、表示し終わっていたら次の文へ進む。
- 表示し終わると、右下に ▼ を点滅させる。
- キーボードの Enter・Space でもクリックと同じ動きをする。

## お知らせ

- 保存したとき・再開したときに、画面下に短いお知らせを 2 秒間表示する。
