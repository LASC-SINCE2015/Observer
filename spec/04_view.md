# 画面・UI 仕様

画面は「タイトル」「章選択」「このゲームについて」「監視室（ゲームの本体）」の 4 つです。要件の番号は [05_requirements.md](05_requirements.md) を参照。

## タイトル画面

- 「はじめから」「つづきから」「章を選ぶ」「記録」「このゲームについて」「音: あり／なし」を並べる。
- セーブがないときは「つづきから」を押せないようにする。章をクリアしていないときは「章を選ぶ」「記録」を押せないようにする。
- 設定は、監視室の画面の「メニュー」（音・時間切れ）に置く。

## 記録の画面

- タイトルと章選択の「記録」から開く（画面に重ねて出す）。通常解決・真解決・バッドエンドの数と、章ごとの状態、見たバッドエンドの題を並べる。

## このゲームについて

- タイトルから開く。ゲームの概要（プロローグで明かされる範囲だけ）、遊び方の要点、内容についての注意、対象年齢の目安（15 歳以上）、相談窓口の案内、バージョンを載せる。
- 注意の文: 「この作品には、人の死・自殺を思わせる場面・性的なことをほのめかす場面が含まれます」。

## 章選択の画面

```
┌──────────────────────────────┐
│ 第1章 欲望の代償                  ✔ │ ← 緑と印（真解決を果たした）
│ 第2章 蜜の味と脅迫                   │ ← 琥珀色（真解決ができるようになった）
│ 第3章 消えた愛人とタイムパラドックス │ ← 白（クリア）
│ 第4章 追い詰められた観測者           │ ← 灰色（未クリア）
└──────────────────────────────┘
```

- 章の状態の色は [02_gameplay.md](02_gameplay.md)「章の選択」のとおり。
- 状態が変わったときは、その章の文字の色がゆっくり変わる。
- 条件を満たすまで出ない章は、行そのものを出さない。

## 監視室の画面

上から次の順に並べます。**テキストウィンドウは、大画面のすぐ下**に置きます（モニター壁・タイムラインの有無で、文章の位置が動かないようにするため）。

```
┌───────────────────────────────────────┐
│ 第1章  2日目 02:00                          v0.3.0 │ ← ステータス
├───────────────────────────────────────┤
│ ┌───────────────────────────────────┐ │
│ │ CAM-03 1F バックヤード     ◀◀ PLAYBACK │ │
│ │ PAST 2日目 01:30                  │ │ ← 大画面（選んだ 1 台）
│ │          （監視映像）              │ │
│ └───────────────────────────────────┘ │
│ 【私】                                 │
│ ……おいおい、嘘だろ。                 ▼ │ ← テキストウィンドウ
├───────────────────────────────────────┤
│ ▶ 巻き戻す                             │ ← 選択肢
├───────────────────────────────────────┤
│ ◀1h ◀10m ◀1m ──●──────▲──▲── 1m▶ 10m▶ 1h▶ │ ← タイムライン（過去の映像のときだけ）
├───────────────────────────────────────┤
│ [01 1F ロビー][02 1F ショップ][03 1F 東廊下]…   │ ← モニター壁（名前だけ）
│ [06 6F EVホール][07 6F 事務所][09 屋上]…        │
├───────────────────────────────────────┤
│ [現在][過去]  [ログ][アイテム][手帳][履歴]  [オート][既読スキップ][保存][メニュー] │ ← 操作ボタン

```

## 雰囲気

- 深夜の薄暗い監視室。黒・ダークグレーを基調にする。
- 映像の色: 現在の映像と録画は緑（録画は少し暗め）、過去の映像はアンバー。テキストウィンドウの左の線や、選ばれているボタンの色もこれに合わせる。

## 大画面（監視モニター）

- 16:9。320x180 の粗い映像を拡大して表示する。
- 演出: ざらついたノイズ、走査線、上から下へ流れる明るい帯、画面の端の暗さ、ときどき起きる横方向のずれ、ちらつき。
- カメラや映像モードを切り替えた瞬間は、映像を大きく乱す。
- 左上にカメラ名・場所・モード・日時、右上に「● REC」（録画は「REC PLAY」、過去の映像は「◀◀ PLAYBACK」）を表示する。
- 過去の映像で干渉できる機器は、点滅で示す。押すと、使える干渉（音・ノイズ・文字）を選ぶ小さなメニューが出る。
- 焼き付いた時間帯（干渉したカメラの、その時間だけ）では、映像を薄く白くかすませて固める（札は出さない。向こう側の映像は見える）。干渉の点滅は出さない。
- 音が入るカメラでは、右上に小さな音のマークを出す。

## タイムライン

- 過去の映像のときだけ、大画面のすぐ下に出す。
- 右端が今の時刻。さかのぼれるのは 72 時間前までだが、つまみの幅は「過去が見えるカメラの、いちばん早い出来事の 1 時間前」までにしぼる（30 分戻すだけでも、つまみがはっきり動くように）。つまみは 1 分単位で動く。
- 大画面のカメラで「何かが映る時刻」に印（▼）を付ける。まだ見ていない時刻は白抜き、見た時刻は塗りつぶし。印を押すと、その時刻へ飛ぶ。
- 両側に「1 時間／10 分／1 分」戻す・進めるボタンを置く。
- 焼き付いた時間帯は、そのカメラのタイムライン上に白い帯で示す。
- 残り時間を出す場面では、タイムラインの上に「あと 58 分」のように出す。

## モニター壁

- その章で使えるカメラを、**名前だけのボタン**で並べる（映像は出さない。スマホでも場所をとらないように）。押すと、そのカメラが大画面に映る。
- 大画面に映しているカメラのボタンは、映像モードの色で縁取る。
- 映らないカメラも 1 つのボタンとして並べる。
- まだ見ていないものがあるカメラのボタンには、点滅する点を付ける。
- 横に並びきらないときは折り返す。スマホの縦画面では 2 列にする。
- 監視室の外の場面・画面を拭くあいだなど、カメラを切り替えられないときは、ボタンを消さずに**グレーにして押せなくする**（画面の位置がずれて、押す場所が変わらないようにするため）。

## 操作ボタン

- 映像モード（現在・録画・過去）、現在での行動（電話・放送・設備・ログ）、アイテム、手帳、文章の履歴、オート、既読スキップ、保存、メニュー（設定・タイトルへ）。
- 探索中に文章を読んでいる途中でカメラや時刻を切り替えたら、その文章は打ち切り、新しく映したものの文章を読む（打ち切った文章は、あとでもう一度読める）。
- その場面で使えない操作は、押せない見た目にする。
- 電話・放送・設備は、押すと相手や文面を選ぶ一覧が出る。ログは、一覧を大画面に重ねて出す。

## テキストウィンドウ

- 話している人の名前を【 】で表示する（地の文は名前なし）。
- 1 文字ずつ表示する。表示中にクリックすると全文を出し、表示し終わっていたら次の文へ進む。
- 表示し終わると、右下に ▼ を点滅させる。
- キーボードの Enter・Space でもクリックと同じ動きをする。
- **オート**: 押すと、文章を読み終えるころに、自動で次へ進む（文章の長さに合わせて待つ）。選択肢・探索・手帳などを開いているあいだは止まる。もう一度押すと止まる。既読スキップとは、どちらか一方だけ。設定はブラウザに覚える。
- テキストウィンドウは、大画面のすぐ下に置く。モニター壁・タイムライン・操作ボタンは、その下に置く（場面によって、文章の位置が動かないように）。

## アイテム欄

- ステータスの「アイテム」かメニューから開き、画面の上に重ねて出す。
- アイテムを一覧で並べ、押すと拡大した画像と説明を出す。静止画には、撮られた日時とカメラ名を添える。

## 予告

- 章の始めの予告（文字のない映像）では、時刻・モニター壁・操作ボタン・文章の枠を隠して、映像だけを見せる（`@cinema on`）。

## 監視室の外の場面

- 監視室の外の場面では、タイムラインを隠し、モニター壁と「現在／過去」はグレーにする。大画面の位置に背景（または黒い画面）を出す。**カメラ越しの映像ではなく八島の目で見ている場面なので、ノイズ・走査線・色かけ・暗い縁をかけず、はっきり見せる。**
- ニュースの音声だけの場面は、黒い画面に文字だけで見せる。

## お知らせ

- 保存したとき・再開したときに、画面下に短いお知らせを 2 秒間表示する。

## スマホの縦画面

- 幅 360px 程度まで操作できるようにする。
- 縦に並べる順は同じ。モニター壁は 2 列の名前ボタン、操作ボタンは折り返す。
- タイムラインのつまみと印は、指で押せる大きさ（目安 40px 以上）にする。
