# ゲームの仕組み

要件の一覧と番号は [05_requirements.md](05_requirements.md) を参照。

## 基本の流れ

1. テキストウィンドウの文章を読む（クリックで次へ）。
2. 文章を読み終えると、選択肢が出る。選ぶと次の場面へ進む。
3. 選択肢とは別に、いつでもカメラと映像モードを切り替えられる。切り替えると、その映像の説明が表示され、読み終えると元の場面の選択肢に戻る。
4. 場面によっては、モニターの中の機器を押す（干渉）、監視室の設備を操作する（現在での行動）、などの操作で先へ進む。

## 作中の時刻

- 作中の日付と時刻（「n 日目 hh:mm」）があり、画面に出る。
- 時刻は、基本的に場面や操作で進む。現実の時間では進まない（一部の、タイミングを選ぶ操作だけ例外）。
- ある時刻までに何かをしなければならない場面では、残り時間を画面に出す。

## 映像モード

| モード | 表示 | 色 | 内容 |
|---|---|---|---|
| 現在の映像 | LIVE / ● REC | 緑 | 今のカメラの様子 |
| 録画 | REC PLAY | 緑（暗め） | 記録された映像。「点検のため停止」など、映っていない時間がある |
| 過去の映像 | PAST / ◀◀ PLAYBACK | アンバー | 異常によって見える、本当の過去 |

### 過去の映像

- タイムラインのつまみを動かして、見る時刻を選ぶ。さかのぼれるのは、今の時刻から最大 72 時間前まで。
- 何かが映る時刻を一度見つけると、タイムラインに印が付き、次からは印を押してそこへ飛べる。
- 「1 時間／10 分／1 分」戻す・進めるボタンもある。
- 過去が見えるカメラは、場面ごとに決まっている。見えないカメラを過去にすると、ノイズしか映らない。

## 過去への干渉

過去の映像を見ているときに、過去に向けて微弱な干渉を与えられます。

| 干渉 | 内容 |
|---|---|
| 音 | 過去の場所のベル・スピーカー・電話などを鳴らす |
| ノイズ | 映像や音声に乱れを起こし、過去の人物の注意を引く |
| 文字 | 過去の表示板や端末に短い文字を出す |

- 干渉できる機器は、過去の映像の中で点滅する。押すと、その機器で使える干渉を選べる。
- 物は動かせない。人は、音や文字に気づいて自分で動く。
- 干渉すると、その場で「現在」が変わる。現在の映像やログは、変わったあとのものになる。
- 一度干渉した時間帯は「焼き付き」、もう干渉できない（映像が白く焼けて見える）。見るだけなら焼き付かない。
- 干渉には、思わぬ形で現在がゆがむことがある。
- 人を誘導するときは、まず過去を見て、何もしなければ人がどう動くかを確かめる。音を置く時刻は、プレイヤーが時刻のつまみで合わせる（干渉しても、時刻はひとりでに進まない）。置く時刻が早すぎたり遅すぎたりすると、うまくいかない。
- 外れの機器を押すと、その時刻は焼き付き、人は別の動きをする。立て直せる道が残ることもある。失敗したときは「この夜を、もう一度」で誘導の最初からやり直せる（日は進まない）。

## 現在での行動

監視員として、監視室からできる操作です。

| 操作 | 内容 |
|---|---|
| 電話 | 内線・外線で、相手と言う内容を選んでかける |
| 館内放送 | 放送の文面を選んで流す |
| 設備の操作 | 扉の施錠・解錠など |
| 警報への対応 | 呼び出しに応じる／応じない |
| ログを見る | 防災盤の作動記録・入退館ログ・録画の停止記録など |

うまくいかなかった操作（はずれ）は、時刻を進めずに選び直せます。

## 八島の手帳

- 八島は、日報には「異常なし」としか書かない。その代わり、モニターで見た「人の見られたくない顔」を、胸ポケットの手帳に一行ずつ書き留めている。
- モニターを見て回ると、手帳に一行が増える（「手帳に書き留めた」と短く出る）。集めなくても話は進む。
- 手帳は、いつでも開いて読める（文章を読んでいる途中や、過去の映像を見ている途中でも）。行ごとに、日時・カメラ・八島の一言が並ぶ。新しく書いた行には印が付く。
- 手帳の中身は、章をまたいで残る。

## アイテムと手がかり

- 手に入れた静止画・証拠などはアイテム欄に入り、拡大して見られる。
- 手がかりは、いつ・どこで見たかと一緒に一覧で見られる。前の章で見たものも残る。
- 持っているアイテムや手がかりによって、出る選択肢が変わる。
- 章によっては、手がかりを並べて整理したり、相手につきつけたりする推理の場面がある。

## フラグ

進行状況はフラグ（立っている／立っていない）で管理します。

| 種類 | 内容 |
|---|---|
| 進行 | 物語の進み具合 |
| 手がかり・アイテム | 手に入れたもの |
| 解決 | 章ごとの結末（通常解決・真解決） |

フラグの名前の付け方は [design/data](../design/data/README.md) を参照。

## 解決

各章には 2 種類の結末があります。

| 結末 | 内容 |
|---|---|
| 通常解決 | 事件は表向き解決するが、謎が残り、後の章に影響が出る。1 周目はこちらで次の章へ進む |
| 真解決 | 条件を満たしたときだけ出る選択肢から進む結末。終わると章選択の画面に戻る |

- 最終章は、条件を満たすまで章選択に出ない。
- 最終章には、選択で分かれる 2 つのエンディングがある。どちらも最後まで遊べる。

## 章の選択

- クリアした章は、章選択の画面からいつでも選び直せる。後の章で得た知識やアイテムを持ったまま戻れる。
- やり直して結末が変わると、後の章の状況も変わる。
- 章の状態は、文字の色と印でわかる。

| 状態 | 表示（例） |
|---|---|
| 未クリア | 灰色 |
| クリア（通常解決） | 白 |
| 真解決ができるようになった | 琥珀色 |
| 真解決を果たした | 緑と印 |

- 選び直した章では、既読の文章を飛ばしたり、分かれ道の場面から始めたりできる。

## バッドエンド

- 選択によっては、短いバッドエンドになる。数十秒で終わり、エンディング名が出る。
- バッドエンドのあとは、選択の直前からやり直せる（作中の日は進まない）。

## セーブ

- 「状態を保存する」を押すと、章・場面・時刻・カメラ・映像モード・フラグ・アイテムを保存する。
- 章ごとの解決状態など、章をまたぐ記録は、場面のセーブとは別に残る。
- ページを開き直すと、保存した場面の最初から再開する。
- 「最初から」を押すと、確認のあと、保存したデータを消して最初から始める。
