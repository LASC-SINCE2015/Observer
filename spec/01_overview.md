# 概要・機能一覧・非機能要件

## 概要

| 項目 | 内容 |
|---|---|
| タイトル | Observer（仮） |
| ジャンル | サスペンス・アドベンチャー（ノベル＋監視カメラ調査） |
| 舞台 | 都心の高級複合ビル「アークレジデンス＆タワー」地下2階の中央監視室（深夜） |
| 構成 | 全5章 |
| 遊ぶ環境 | PC・スマホの Web ブラウザ |
| 公開 | GitHub Pages（無料） |

プレイヤーは夜勤の監視員・八島 陸として、監視カメラの映像を見ながら事件を追います。カメラを「過去の映像」に切り替えると、事件が起きた時刻の様子を見ることができ、さらに過去へ微弱な干渉を与えられます。見つけた手がかりと干渉によって結末が変わります。

## 機能一覧

機能ごとの要件と、いまの実装の状態は [05_requirements.md](05_requirements.md) にまとめています。v0.2.5 で遊べるのは第1章（通常解決・バッドエンド・真解決）です。

## 非機能要件

- 外部ライブラリ・CDN を使わない（オフラインでも、ファイルを直接開いても動く）。
- サーバーを使わない。セーブは端末のブラウザの中だけに残る（端末・ブラウザをまたいだ引き継ぎはしない）。
- スマホの縦画面でも操作できる（幅 360px 程度まで）。
- 作成・運用とも無料。
