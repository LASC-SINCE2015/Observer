# 概要・機能一覧・非機能要件

## 概要

| 項目 | 内容 |
|---|---|
| タイトル | Observer（仮） |
| ジャンル | サスペンス・アドベンチャー（ノベル＋監視カメラ調査） |
| 舞台 | 深夜のオフィスビルの中央監視室 |
| 遊ぶ環境 | PC・スマホの Web ブラウザ |
| 公開 | GitHub Pages（無料） |

プレイヤーは夜間の監視員として、監視カメラの映像を見ながら事件を追います。カメラを「過去の映像」に切り替えると、事件が起きた時刻の様子を見ることができ、そこで見つけた手がかりによって結末が変わります。

## 機能一覧

| 機能 | 内容 | 状態 |
|---|---|---|
| 監視モニター | Canvas に監視映像を描く。ノイズ・走査線・映像の乱れの演出 | 実装済み |
| カメラ切り替え | CAM-01〜03 の切り替え | 実装済み |
| 映像モード切り替え | 「現在の映像（LIVE）」と「過去の映像（PAST）」の切り替え。モニターの色（緑／アンバー）と文章が変わる | 実装済み |
| テキストウィンドウ | 1 文字ずつ表示する。クリック・Enter・Space で全文表示／次へ | 実装済み |
| 選択肢 | 場面ごとの選択肢。フラグがそろったときだけ出る選択肢がある | 実装済み |
| ステータス表示 | 現在の章・通常解決・真解決・手がかりの数 | 実装済み |
| セーブ | 「状態を保存する」で `localStorage` に保存。開き直すと自動で再開 | 実装済み |
| 最初から | セーブを消して最初から始める | 実装済み |
| 画像・音の素材 | 背景画像・効果音・BGM | **未実装** |
| 複数のセーブ枠 | — | **未実装** |

## 非機能要件

- 外部ライブラリ・CDN を使わない（オフラインでも、ファイルを直接開いても動く）。
- サーバーを使わない。セーブは端末のブラウザの中だけに残る（端末・ブラウザをまたいだ引き継ぎはしない）。
- スマホの縦画面でも操作できる（幅 360px 程度まで）。
- 作成・運用とも無料。
