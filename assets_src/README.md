# 素材の元ファイル (assets_src)

画像・音などの素材の、編集用の元ファイルを置くフォルダです。このフォルダは公開されません。
ゲームで使う形に書き出したものは `game/assets/` に置きます。

今は素材を使っていません（モニターの映像は Canvas で描いています）。

## 置き方

| フォルダ | 内容 |
|---|---|
| `images/` | 画像の元ファイル |
| `sounds/` | 効果音・BGM の元ファイル |

## 素材の一覧とライセンス

外部の素材を使うときは、必ずここに記録します。

| ファイル | 作者・入手元 | ライセンス | クレジット表記 |
|---|---|---|---|
| （なし） | | | |

## 注意

- 大きなファイル（数 MB 以上）が増えるとリポジトリが重くなります。Git LFS は無料枠（1GB）を超えると有料になるため、使う前に相談します。
