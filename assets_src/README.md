# 素材の元ファイル (assets_src)

画像・音などの素材の、編集用の元ファイルを置くフォルダです。このフォルダは公開されません。
ゲームで使う形に書き出したものは `game/assets/` に置きます。

## 置き方

| フォルダ | 内容 |
|---|---|
| `images/chars/` | 立ち絵の元ファイル（緑一色の背景（グリーンバック）か、背景を透明にした PNG） |
| `images/scenes/` | 場面の絵の元ファイル（16:9） |
| `images/bg/` | カメラの背景の元ファイル（16:9、人のいない絵） |
| `sounds/` | 効果音・BGM の元ファイル（今は使っていない。効果音はゲームの中で作っている） |

- `images/` の元ファイルは大きいので、リポジトリには入れません（`.gitignore` で外しています）。手元に残しておいてください。
- 元ファイルを置いたら、リポジトリ直下で次を実行すると、ゲームで使う大きさと形式に変えて `game/assets/` に書き出します（インストール不要。Windows の機能だけで動く）。

```powershell
./tools/optimize_images.ps1
```

| 種類 | 書き出し | 大きさ |
|---|---|---|
| 立ち絵 | `game/assets/chars/<名前>.png` | 高さ 1200px まで（透明はそのまま） |
| 場面・背景 | `game/assets/scenes/<名前>.jpg`・`game/assets/bg/<名前>.jpg` | 1280x720（真ん中を 16:9 に切り抜く） |

- ファイル名は、下の一覧の名前にしてください（拡張子は .png でも .jpg でもよい）。名前が合っていれば、ゲームが自動で使います。**絵がまだない場所は、今までどおりの線の絵で動きます。**
- 絵が入ったら、干渉できる機器（非常ベルなど）の点滅の位置を、絵に合わせて直します（台本の `@hotspot` の座標）。

## 絵の作り方（画像生成 AI）

### サービス

無料で使える画像生成 AI（ChatGPT・Gemini など）で作ります。

- **使う前に、そのサービスの利用規約で「作った画像を、無料で公開するゲームに使ってよいか」を確かめてください。** 使ったサービスは、下の「素材の一覧とライセンス」に記録します。
- 実在の人物・作品・ブランドに似せない（名前を出さない）。
- 露出は服の範囲まで。色気は、服・表情・しぐさ・光で出す。密会の場面の立ち絵（`saeki_flushed`・`jogasaki_aroused`・`jogasaki_after`）だけは、服を大きく乱し、下着が少しのぞく程度まで。裸・胸があらわな姿・性的な行為は描かない（公開するゲームのため。多くのサービスでも断られる）。

英語のサイト向けのプロンプト（そのまま貼り付けられる形と、Stable Diffusion 系のサイト向けの書き方）は [prompts_en.md](prompts_en.md)。

### 絵柄をそろえるコツ

1. 最初に玲子の `normal` を作り、気に入るまで作り直す。
2. 2 枚目からは、気に入った絵を添付して「この絵と同じ絵柄・同じ塗りで」と頼む。同じ人物の表情違いは、「同じ人物、同じ服、表情だけ〇〇に」と頼む。
3. 立ち絵は、クロマキー用の緑一色の背景（グリーンバック）で作る。そのまま置けば、変換スクリプトが緑の背景を自動で透明にする（白い背景は、服や肌・髪のすき間と区別しにくく、きれいに抜けないのでやめた）。人物の服などに緑が多いときは、青一色（ブルーバック）にする。

### 共通の指示（毎回、最初に付ける）

**立ち絵**

> 日本のアニメ調のイラスト。大人向けのサスペンス・ノベルゲームの立ち絵。繊細な線、セル画風のくっきりした影、少し落ち着いた色。腰から上、体はやや斜め、顔はこちらを向く。縦長（2:3）。背景はクロマキー用の明るい緑一色（グリーンバック）。影やグラデーションのないベタ塗りで、人物の輪郭はくっきり。人物に緑の光や照り返しを入れない。文字・ロゴ・透かしは入れない。

**場面の絵・背景**

> 日本のアニメ調の背景美術。深夜の高級タワービルの中を、天井の隅の防犯カメラから見下ろした構図（広角レンズの少しゆがんだ見え方）。夜の薄暗い照明、静かで不穏な空気。横長（16:9）。文字・タイムスタンプ・ロゴ・透かしは入れない（ゲームの側で付けるため）。

## 注意

- 大きなファイル（数 MB 以上）が増えるとリポジトリが重くなります。`game/assets/` には、`tools/optimize_images.ps1` で小さくしたものだけを入れます。Git LFS は無料枠（1GB）を超えると有料になるため、使う前に相談します。
