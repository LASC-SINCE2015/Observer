# 処理の流れ

## 起動

1. カメラのボタンを作る。
2. `localStorage` からセーブを読む。あれば `state` に入れ、「保存した状態から再開します」と表示する。
3. `state.sceneId` の場面に入る（`enterScene`）。
4. モニターの描画を始める。

## 場面に入る（enterScene）

1. 場面の `chapter` / `camera` / `mode` があれば `state` を変える。
2. `set` のフラグを立てる。
3. ステータス・ボタンの表示を更新し、選択肢を消す。
4. `lines` を 1 文字ずつ表示する。
5. すべて読み終えたら、`set_after` のフラグを立て、選択肢を表示する。

## 映像を切り替える（switchFeed）

1. `state.camera` / `state.mode` を変え、ボタンの表示を更新する。
2. 映像を数フレーム大きく乱す。
3. その映像に `onView` があり、条件のフラグが立っていれば、フラグを立てる。
4. 選択肢を消し、映像の説明（`lines`）を表示する。
5. 読み終えたら、場面の選択肢を表示し直す。
   - 場面の文章の途中で切り替えた場合は、場面を読み終えたときの処理（`set_after` と選択肢）を代わりに行う。

## セーブ

1. 「状態を保存する」を押す。
2. `state` を JSON にして `localStorage` に保存する。
3. 成功・失敗をお知らせで表示する。

## 最初から

1. 確認のダイアログを出す。
2. OK なら、セーブを消し、`state` を初期化して最初の場面に入る。
