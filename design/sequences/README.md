# 処理の流れ

## 起動（`init`）

1. 無い絵（404）の記憶を読み込む（[ADR 0008](../decisions/0008_remember_missing_images.md)）。
2. バージョンを表示する。台本の読み込みのエラーと、ない命令を調べて、コンソールに出す（`?debug` のときは画面にも出す）。
3. 章をまたぐ記録（`progress`）を読み、音・オートの設定を戻す。
4. タイトル画面を出す。「つづきから」は、保存した場面があるときだけ押せる。

## 章を始める（`startChapter`）

1. 状態を新しく作る（`newWorld`）。手帳には、前の章までの、通常解決で終えたときの手帳を入れる（章を選んで始めたとき。続けて次の章へ進んだときは、いまの手帳を引き継ぐ）。
2. モニター壁を作り、台本の絵を先に読み込み、監視室の画面を出す。
3. 章の始めのラベル（`data/chapters.js` の `start`）へ `go` する。

## 台本を進める（`go` → `step`）

1. `go(ラベル)` は、ラベルの位置へ `pc` を移し、時間切れの設定を解除して、選択肢を消し、`step` を呼ぶ。ラベルがなければ、遊ぶ人には見せずに直前の選択肢へ戻す。
2. `step` は、命令を上から順に `OPS` で実行する。プレイヤーを待つ命令（文章・選択肢・拭く操作・題名のカード・エンディング）で止まり、操作されたら続きを実行する。
3. ラベルに入るたびに、状態を丸ごと写し取って自動で保存する（`checkpoint`）。

## 探索（`@choice` で止まっているあいだ）

1. カメラの切り替え（`switchCam`）・映像モードの切り替え（`switchMode`）・過去の時刻の移動（`setPast`）のたびに、映像を数フレーム乱す。
2. 見たことのない `@look`（現在）・`@event`（過去）があれば、本文を読み、読み終えたらフラグを立てて、選択肢を出し直す（`checkExplore`）。読んでいる途中でカメラを切り替えたら、その文章は打ち切り、あとでもう一度読める。
3. 過去の映像で、点滅する機器（`@hotspot`）を押すと、動作を選ぶメニューが出る。選ぶとラベルへ飛ぶ（干渉）。干渉した時間帯は焼き付く。
4. `@idle` があるときは、選択肢が出ているあいだだけ時間切れのタイマーを動かし、時間がたつとラベルへ飛ぶ。押される・場面が変わるたびに数え直す。

## 保存

1. ラベルに入るたびに、`checkpoint` を `observer.save.v2` に保存する（`autosave`）。章をまたぐ記録（`observer.progress.v2`）も一緒に保存する。
2. 「保存」ボタンは、同じ内容をもう一度保存し、お知らせを出す（`manualSave`）。
3. 保存に失敗しても（プライベートウィンドウ・容量超過）、遊びは続ける。

## つづきから・はじめから

1. 「つづきから」: 保存した場面を読み込み、そのラベルの最初から台本を実行し直す。台本が書き換わってラベルがなければ、章の始めから。
2. 「はじめから」: 保存があれば確認を出し、OK なら第1章の最初から始める。章をまたぐ記録は残る。「記録を全部消す」は `?debug` のデバッグの枠にある。

## バッドエンドからのやり直し

1. `@ending bad` のカードに「やり直す」を出す。
2. 押すと、指定のラベルに入ったときの状態（`labelSnaps`）に戻して、そのラベルから再開する。作中の日は進まない。
