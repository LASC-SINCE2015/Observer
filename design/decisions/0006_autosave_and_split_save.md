# 0006 場面のセーブは自動保存にし、章をまたぐ記録と分ける

- 状態: 採用（[0002](0002_save_in_localstorage.md) を置き換える）
- 日付: 2026-11-22（実装は v0.2 系の途中で変更。ここで記録）

## 状況

0002 では、「保存」ボタンを押したときだけ、1 つのキー（`observer.save.v1`）に保存すると決めた。章が増え、章選択・周回・既読スキップ・手帳の持ち越しが入ると、「いまの場面の状態」と「章をまたいで残るもの（章の結末・既読・見たエンディング・設定）」は、消えるタイミングが違うことがわかった。また、スマホではボタンを押し忘れて、ブラウザを閉じると進みが消える。

## 決定

- 保存は 2 つのキーに分ける。どちらも JSON で、`version` を持つ。
  - `observer.save.v2`: 場面のセーブ。ラベルに入るたびに、状態を丸ごと自動で保存する。「保存」ボタンは、同じ内容をもう一度保存して知らせるだけ。
  - `observer.progress.v2`: 章をまたぐ記録（章の結末・章をまたぐフラグ・見たエンディング・既読・手帳・設定）。結末などが変わるたびに保存する。
- 形式を変えたときは、キーの `v` と `version` を両方上げ、古いデータは読み込まずに、ないものとして扱う。項目を足すだけなら、読み込むときに足りない項目を初期値で補う（`version` は上げない）。
- 保存できない環境（プライベートウィンドウ・容量超過）でも、エラーにせず、保存しないまま遊べる。
- 形式の詳細は [data/README.md](../data/README.md)。

## 理由

- ラベルは場面の区切りなので、そこで保存すれば、再開しても、場面の最初から自然に読み直せる。
- 章をまたぐ記録を分けておけば、「はじめから」や章の選び直しで、結末や既読を消さずに済む。

## 影響

- 再開は、保存したラベルの最初から台本を実行し直す。途中の文までは戻らない。
- 台本を書き換えると、ラベルがなくなって再開できなくなることがある（そのときは章の始めから）。既読は「台本の名前:行番号」で持つので、台本を書き換えるとずれる。
- 端末・ブラウザをまたいだ引き継ぎはできない（0002 のまま）。
