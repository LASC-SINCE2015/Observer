# 0002 セーブはブラウザの localStorage に保存する

- 状態: 採用
- 日付: 2026-11-03

## 状況

進行状況（章・フラグ）を保存し、ページを開き直しても続きから遊べるようにしたい。GitHub Pages は静的なファイルしか置けない。

## 決定

- ブラウザの `localStorage` に、キー `observer.save.v1` で JSON を保存する。
- 保存は「状態を保存する」ボタンを押したときだけ行う（自動保存はしない）。

## 理由

- サーバーが不要で、費用がかからない。
- 保存するデータは小さい（数百バイト）ので、`localStorage` の容量（5MB 程度）で十分。

## 影響

- セーブは端末・ブラウザごと。別の端末への引き継ぎはできない。
- ブラウザのデータを消すと、セーブも消える。プライベートブラウズでは、閉じると消えることがある。
- 形式を変えるときは、キーと `version` を上げる（[data/](../data/README.md)）。
