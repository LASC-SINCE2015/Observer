# 0004 シナリオのデータを章ごとの JS ファイルに分ける

- 状態: 採用
- 日付: 2026-11-08

## 状況

[0001](0001_single_html_no_library.md) では、最初は `game/index.html` の 1 ファイルにまとめると決めた。全5章のシナリオ（場面・カメラ・干渉・アイテム）を入れると数千行になり、1 ファイルでは編集しにくく、章ごとの変更の差分も追いにくい。

## 決定

- 仕組み（描画・進行・セーブ・UI）は `game/index.html` に残す。
- シナリオのデータは、章ごとに `game/data/chapter1.js` 〜 `chapter5.js` に分ける。章をまたいで使うデータ（カメラの一覧・アイテムの一覧など）は `game/data/common.js` に置く。
- 読み込みは通常の `<script src>` で行う。各ファイルは、決まったグローバルの入れ物（例: `window.OBSERVER_DATA`）にデータを足していく。
- ES Modules（`import`）・ビルドツールは使わない。外部ライブラリを使わない方針（0001）は変えない。

## 理由

- `<script src>` なら、ファイルを直接開いたとき（`file://`）も GitHub Pages でも、そのまま動く。
- 章ごとにファイルが分かれていれば、シナリオを書く作業と仕組みを作る作業がぶつかりにくい。
- 0001 の「影響」に書いた、分けるときのやり方のとおり。

## 影響

- 0001 の「1 ファイルにまとめる」の部分は、この ADR で置き換える（外部ライブラリを使わない部分は 0001 のまま）。
- `index.html` の `<script src>` の並び順（共通 → 各章 → 仕組み）を守る必要がある。
- データの形式は [design/data](../data/README.md) に書く。
