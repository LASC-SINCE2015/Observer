# 0001 外部ライブラリを使わず、1 ファイルの HTML で作る

- 状態: 採用
- 日付: 2026-11-03

## 状況

ブラウザで動くアドベンチャーゲームを、無料で公開・運用したい。ゲームエンジンやフレームワークを使う方法もある。

## 決定

- 純粋な HTML5 / CSS / JavaScript で作り、外部ライブラリ・CDN は使わない。
- 最初は `game/index.html` の 1 ファイルにまとめる。

## 理由

- ビルドやインストールが不要で、ファイルを開くだけで動作を確認できる。
- 外部のサービスに依存しないので、オフラインでも動き、ライブラリの更新に振り回されない。
- アドベンチャーゲームに必要な機能（文章・選択肢・簡単な描画・保存）は、ブラウザの標準機能で足りる。

## 影響

- シナリオや素材が増えると 1 ファイルが大きくなる。そのときは、シナリオのデータ（`SCENES`・`CAMERAS`）を `game/` 内の別の JS ファイルに分ける（新しい ADR を作る）。
- ES Modules（`import`）は、ファイルを直接開いたとき（`file://`）に動かないため、分けるときは通常の `<script src>` で読み込む。
