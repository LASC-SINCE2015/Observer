# 台本の書き方

シナリオは、章ごとの台本ファイル（`game/scenario/chapter<N>.js`）に、テキストで書きます。台本は上から順に実行されます。プログラムの知識がなくても書き換えられるよう、決まった形の「命令」と、ふつうの文章だけで書けるようにしています。

```js
Observer.script('chapter1', `
@cast 八島 佐伯
*start
@time 1/21:00
@cam CAM-01 live
地の文は、そのまま 1 行に書く。1 行が 1 回のクリックで表示される。
八島「セリフは、名前「…」の形で書く」
@choice
- 選択肢の文 -> *次のラベル
`);
```

- 台本は `` ` ``（バッククォート）で囲んだ中に書きます。台本の中では、バッククォートと `${` は使えません。
- 台本を書き換えたら、ブラウザで開き直すだけで反映されます。ラベルの書き間違いや、ない命令は、画面の上に赤い枠で知らせます。
- 自動テスト `node tools/playtest.js <章> <ルート>` で、最後まで通して遊べるか確かめられます（[tools/README.md](../../tools/README.md)）。

## 行の種類

| 行 | 意味 |
|---|---|
| `// …` | コメント（画面には出ない）。**画面に出さない真相のメモは書かない**（公開されるため） |
| `*名前` | ラベル（場面の始まり）。ジャンプ先になる。ラベルに入るたびに自動で保存される |
| `@命令 …` | 命令（下の一覧） |
| `名前「…」` | セリフ。名前が `@cast` に書いてあるときだけセリフになる（それ以外は地の文） |
| `- 文 -> *ラベル` | 選択肢（`@choice` の直後に並べる） |
| 字下げした行 | 直前の `@look`・`@event` の本文 |
| それ以外 | 地の文 |

空行は無視されます。

## 書き方の決まり

| もの | 書き方 | 例 |
|---|---|---|
| 時刻 | `日/時:分` | `2/01:30`（2 日目の 1 時 30 分） |
| 時間帯 | `日/時:分-日/時:分` | `2/01:28-2/01:45` |
| 人物（影） | `種類@x` または `種類@x,y` または `種類@x,y,大きさ` | `woman@170`、`sitman@80,140`、`man@150,120,0.6` |
| 条件 | フラグ名を `&` か空白でつなぐ（すべて満たすとき） | `saw_reiko & !saw_log` |

- 人物を書くところには、`img:パス` で場面の絵も書けます（例: `img:scenes/ch1_reiko_look.jpg woman@170`）。絵のファイルがあれば絵だけを出し（人物も絵に入っている）、まだなければ人物の影を描きます。パスは `game/assets/` から。
- 人物の座標は、320x180 の画面の中の位置です。`y` は足もとの高さで、省略すると 150（床）。
- 人物の種類: `man`（男）・`woman`（女）・`oldman`（白髪の男）・`cleaner`（モップを持った清掃員）・`guard`（帽子の人。警官・警備員）・`sitman` / `sitwoman`（座っている人）・`couple`（寄り添う 2 人）・`box`（物の影）
- 条件に書けるもの: `フラグ`、`!フラグ`（立っていない）、`item:ID`（アイテムを持っている）、`g:フラグ`（章をまたぐフラグ）

## 命令の一覧

### 流れ

| 命令 | 意味 |
|---|---|
| `@cast 名前 …` | セリフを話す人の名前を登録する（ファイルの最初に書く） |
| `@choice [案内文]` | 選択肢を出して止まる。止まっている間、プレイヤーはカメラや過去の時刻を自由に動かせる。案内文はテキストウィンドウに薄く出る。条件を満たす選択肢が 1 つもないときは、案内文だけを出して、プレイヤーが何かを見つける（`@look`・`@event` のフラグが立つ、干渉する）のを待つ |
| `- 文 -> *ラベル [if 条件]` | 選択肢。条件を満たすときだけ出る。フラグが立つと、その場で出し直す |
| `@goto *ラベル` | ラベルへ飛ぶ |
| `@if 条件 -> *ラベル` | 条件を満たすときだけ飛ぶ |
| `@set フラグ …` / `@unset フラグ …` | フラグを立てる / 消す |
| `@gset フラグ …` | 章をまたぐフラグを立てる（ほかの章の条件 `g:フラグ` で使う） |
| `@pause ミリ秒` | 少し待つ |

### 時刻とモニター

| 命令 | 意味 |
|---|---|
| `@time 日/時:分` | 今の時刻 |
| `@pasttime 日/時:分` | 過去の映像で見ている時刻 |
| `@cam ID [live\|past]` | 大画面に映すカメラ（と映像モード） |
| `@mode live\|past` | 映像モード |
| `@power on\|off` | 過去を見る力を使えるようにする（「過去」のボタンとタイムラインが出る） |
| `@open ID … \| all \| none` | 過去が映るカメラ。ほかのカメラは、過去にすると「映らない」 |
| `@cameras ID … \| all` | モニター壁に並べるカメラ |
| `@status ID ok\|broken\|paused [表示する文字]` | カメラの状態。`broken` は NO SIGNAL、`paused` は停止中 |
| `@feed ID 人物 …` | 今の映像に映る人物。人物を書かなければ誰もいない |
| `@look ID [flag=フラグ]` ＋本文 | 今の映像で、そのカメラを初めて見たときに読む文章。読むとフラグが立つ。`@look ID off` で消す |
| `@event ID 時間帯 [flag=フラグ] \| 人物 …` ＋本文 | 過去の映像で、その時間帯に映るもの。初めて見たときに本文を読み、フラグが立ち、タイムラインに印が付く。同じ時刻に重なったときは、あとに書いたものが映る |
| `@noevents ID \| all` | 過去の映像に映るものを消す |

### 立ち絵

| 命令 | 意味 |
|---|---|
| `@show 名前 [表情] [left]` | 立ち絵を出す（ふつうは右、`left` で左）。名前と表情の絵は `data/characters.js` で決める。表情を書かなければ `normal`。絵のファイルがまだなければ何も出ない |
| `@hide [名前 \| all]` | 立ち絵を消す（何も書かなければ全部） |

### 干渉

| 命令 | 意味 |
|---|---|
| `@hotspot ID 時間帯 x,y 名前 [if 条件] \| 動作=*ラベル \| …` | 過去の映像の中の、干渉できる機器。その時間帯に、そのカメラで点滅する。押すと動作を選べ、選ぶとラベルへ飛ぶ。時間帯の代わりに `live` と書くと、今の映像で押せる機器になる |
| `@nohotspots [ID \| 名前]` | 干渉できる機器を消す（何も書かなければ全部） |
| `@burn here` / `@burn 時間帯` | 時間帯を焼き付かせる（もう干渉できない。映像が白く焼ける）。`here` は、最後に押した機器の時間帯 |
| `@relay ID \| 見出し \| ID 日/時:分 人物 …` | 映らないカメラの枠に、一枚の静止画を映す。`@relay off` で消す |

### アイテムとログ

| 命令 | 意味 |
|---|---|
| `@item ID 名前 \| 説明 [\| still=ID 日/時:分 人物 …]` | アイテムを手に入れる。`still=` を書くと、静止画も見られる |
| `@drop ID` | アイテムを手放す |
| `@log 種類 \| 文` | ログ（「ログ」ボタンで見られる記録）に一行足す |

### 場面と演出

| 命令 | 意味 |
|---|---|
| `@outside 背景 場所の名前 \| 人物 …` | 監視室の外の場面にする（モニター壁とボタンを隠す） |
| `@inside` | 監視室に戻る |
| `@fx 演出` | `flash`（画面が白く光る）・`shake`（揺れる）・`glitch`（映像が乱れる）・`splash`（画面に液体が飛ぶ）・`clean`（それを消す）・`black` / `white`（画面を黒く / 白くする）・`unblack`（戻す）・`lamp ID`（カメラの赤いランプを一瞬点ける） |
| `@sound 名前` | 効果音。`bell`・`chime`・`beep`・`phone`・`static`・`glitch`・`power`・`thud`・`siren`・`can` |
| `@wipe [案内文]` | プレイヤーがモニターをなぞる（拭く）まで待つ |
| `@title 小見出し \| 題名` | 黒い画面に題名を出し、クリックを待つ |
| `@ending bad\|normal\|true 題名 [\| *やり直すラベル \| ボタンの文]` | エンディングの画面。やり直すラベルを書くと、そのラベルに入ったときの状態に戻してやり直せる |

### 章

| 命令 | 意味 |
|---|---|
| `@chapter 番号` | 今の章 |
| `@result 番号 normal\|true` | 章の結末を記録する（章選択の色が変わる） |
| `@trueready 番号` | その章を「真解決ができる」にする（章選択で琥珀色になる） |
| `@unlock 番号` | 隠れていた章を章選択に出す |
| `@next 番号` | 次の章を始める（台本がまだない章なら「準備中」） |
| `@select` | 章選択の画面に戻る |

## 背景の種類

カメラの背景は `data/cameras.js` で決めます。`@outside` でも使えます。`data/cameras.js` の `bgimg` に背景の絵を書いておくと、絵のファイルがあるときは、線の背景の代わりに絵を使います。

`room`（監視室）・`lobby`（ロビー）・`shop`（店）・`corridor`（廊下）・`backyard`（倉庫）・`office`（事務所）・`evhall` / `evhall9`（エレベーターホール）・`elevator`（エレベーターの中）・`roof`（屋上）・`stairs`（階段）・`street`（屋外）・`dawn`（屋外の朝）・`dark`（何も描かない）

背景を増やすときは、`js/renderer.js` の `BACKGROUNDS` に関数を足します。

## 絵の入れ方

必要な絵の一覧・ファイル名・作り方は [assets_src/README.md](../../assets_src/README.md)。元の絵を `assets_src/images/` に置いて `./tools/optimize_images.ps1` を実行すると、`game/assets/` に書き出されます。

- 絵が入ったら、干渉できる機器の座標（`@hotspot` の x,y）を、絵の中の機器の位置に合わせて直してください。

## デバッグ

URL の末尾に `?debug` を付けて開くと、右下にデバッグの枠が出ます。ラベルへ飛ぶ、フラグを立てる・消す、章をクリアした扱いにする、記録を全部消す、ができます。
