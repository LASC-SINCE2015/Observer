# テスト・確認 (testing)

Observer で「何を確認するか」と「確認した結果」を残すフォルダです。

## 目次

- [確認内容（テスト計画）](test_plan.md)
- 確認結果
  - （まだありません）

## 確認の種類

| 種類 | 対象 | 実行方法 |
|---|---|---|
| 動作確認 | PC のブラウザ | `game/index.html` をブラウザで直接開き、[test_plan.md](test_plan.md) のチェックリストを確認する |
| テストプレイ | シナリオ・手がかり | 各章を通常解決・真解決の両方で最後まで遊ぶ |
| 実機確認 | スマホのブラウザ・公開サイト | GitHub Pages の URL を開いて確認する |

## 結果の残し方

- 確認したら `results/<日付>_<ブランチ名>.md` を作り、上の目次に追加する。
- 1 ファイルに「対象（ブランチ・コミット）」「環境（ブラウザ・端末）」「結果」「見つかった問題」を書く。
- 失敗した確認も消さずに残し、直したら再確認の結果を追記する。
