# 確認内容（テスト計画）

## 画面

- [ ] ステータスに「第1章　消えた夜警」・通常解決／真解決「未達成」・手がかり「0 / 3」・バージョンが表示される
- [ ] モニターにノイズ・走査線・流れる帯が表示され、ときどき映像がずれる
- [ ] モニター左上にカメラ名・場所・LIVE と時刻が表示され、時刻が進む
- [ ] スマホの縦画面（幅 360px 程度）で横にはみ出さない

## テキストウィンドウ

- [ ] 文章が 1 文字ずつ表示される
- [ ] 表示中にクリックすると全文が出る
- [ ] 表示し終わると ▼ が点滅し、クリックで次の文へ進む
- [ ] Enter・Space でもクリックと同じ動きをする
- [ ] 最後の文を読み終えると選択肢が出る

## 映像の切り替え

- [ ] 「過去の映像」で、モニター・ボタン・テキストウィンドウの線がアンバーになり、右上が「◀◀ PLAYBACK」になる
- [ ] 「現在の映像」で緑に戻る
- [ ] 切り替えた瞬間、映像が大きく乱れる
- [ ] 切り替えると映像の説明が表示され、読み終えると元の場面の選択肢に戻る
- [ ] CAM-01〜03 を切り替えると、絵と場所の表示が変わる
- [ ] 場面の文章の途中で切り替えても、読み終えたあとに選択肢が出る

## シナリオ・フラグ

- [ ] `check_cam3` より前に CAM-03 の過去の映像を見ても、手がかり「影」は増えない
- [ ] `check_cam3` 以降に CAM-03 の過去の映像を見ると、手がかり「影」が増える
- [ ] 入退室の記録を確認すると、「扉の記録」「空白の6分」が増える
- [ ] 手がかりが 3 つそろうまで、真解決の選択肢が出ない
- [ ] 通常解決で、ステータスの通常解決が「達成」になる
- [ ] 真解決で、通常解決・真解決の両方が「達成」になる
- [ ] 第2章へ進むと、章の表示が「第2章」になる

## セーブ

- [ ] 「状態を保存する」で「状態を保存しました」と表示される
- [ ] 保存後にリロードすると、保存した場面・章・フラグ・カメラ・映像モードで再開する
- [ ] 保存していない状態でリロードすると、最初から始まる
- [ ] 「最初から」で確認が出て、OK なら最初から始まり、リロードしても最初から始まる

## 公開

- [ ] master にプッシュすると GitHub Actions が成功し、公開 URL でゲームが動く
- [ ] 公開サイトに spec/ や design/ が含まれていない
