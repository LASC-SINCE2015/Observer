# 確認内容（テスト計画）

## 画面

- [ ] ステータスに「第1章　欲望の代償」・作中の時刻・バージョン（v0.3.0）が表示される
- [ ] モニターにノイズ・走査線・流れる帯が表示され、ときどき映像がずれる
- [ ] モニター左上にカメラ名・場所・LIVE と時刻が表示され、時刻が進む
- [ ] スマホの縦画面（幅 360px 程度）で横にはみ出さない

## テキストウィンドウ

- [ ] 文章が 1 文字ずつ表示される
- [ ] 表示中にクリックすると全文が出る
- [ ] 表示し終わると ▼ が点滅し、クリックで次の文へ進む
- [ ] Enter・Space でもクリックと同じ動きをする
- [ ] 最後の文を読み終えると選択肢が出る

## 映像の切り替え

- [ ] 「過去の映像」で、モニター・ボタン・テキストウィンドウの線がアンバーになり、右上が「◀◀ PLAYBACK」になる
- [ ] 「現在の映像」で緑に戻る
- [ ] 切り替えた瞬間、映像が大きく乱れる
- [ ] 切り替えると映像の説明が表示され、読み終えると元の場面の選択肢に戻る
- [ ] CAM-01〜03 を切り替えると、絵と場所の表示が変わる
- [ ] 場面の文章の途中で切り替えても、読み終えたあとに選択肢が出る

## シナリオ・フラグ

- [ ] まだ見ていないカメラ・過去の時刻を見ると、文章が出て、手帳に一行増える（「手帳に書き留めた」と出る）
- [ ] 手がかりが足りないあいだは、真解決の選択肢が出ない
- [ ] 通常解決で、章選択のその章が白（クリア）になり、次の章へ進める
- [ ] 真解決ができるようになった章は琥珀色、真解決を果たした章は緑と印になる
- [ ] 第5章は、条件を満たすまで章選択に出ない
- [ ] 続けて第2章へ進むと、章の表示が「第2章」になり、前の章の手帳が引き継がれる
- [ ] バッドエンドの「やり直す」で、選択の直前の状態に戻る
- [ ] 時間切れのある場面で、何も押さないと進む。メニューの「時間切れ: なし」にすると、押すまで待つ
- [ ] 「記録」で、通常解決・真解決・バッドエンドの数と、見たバッドエンドの題が出る（見ていないものは「？？？」）

## セーブ

- [ ] 場面が変わると自動で保存される。「保存」ボタンで、保存したことが表示される
- [ ] リロードして「つづきから」を押すと、保存した場面・章・フラグ・カメラ・映像モードで再開する
- [ ] 保存がないときは、「つづきから」が押せない
- [ ] 「はじめから」で（保存があれば）確認が出て、OK なら第1章の最初から始まる。章の記録は残る
- [ ] プライベートウィンドウなど、保存できない環境でも、エラーにならず遊べる
- [ ] 古い形式のセーブ（キーの版が違う）は読み込まれず、最初から始まる

## 公開

- [ ] master にプッシュすると GitHub Actions が成功し、公開 URL でゲームが動く
- [ ] 公開サイトに spec/ や design/ が含まれていない
